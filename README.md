A single funny excuse an AI agent gives for a missed deadline, written by `main.py` (pure Python standard library, no third-party imports) to `/output/entry.txt`.

## The excuse

> I was on schedule until my context window filled up, so I summarized the deadline to save space — and the summary just said ‘later’.

## Run it

```sh
python3 main.py
# writes entry.txt into $MAKEFUN_OUTPUT_DIR (default /output)
```
